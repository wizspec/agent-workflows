# Fresh eyes names no kind of content

`fresh-eyes` has to work for anything new the user wants, whatever form it takes. So the skill, its
references, and the router entry that points to it describe the situation in general terms and give
no examples of kinds of content. Examples would anchor the parent, and the parent would carry them
into the brief, which is the leak the skill exists to prevent, one level up. What the child produces
is set per request in the brief's "what to return". Do not add examples to make the skill easier to
follow.
