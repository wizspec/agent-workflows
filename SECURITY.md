# Security policy

Agent skills can influence tools, files, credentials, network access, and external systems. Review a
skill before installing it and run agents with the least authority appropriate for the task.

Please report a suspected vulnerability through GitHub's private vulnerability reporting for this
repository. Include the affected skill, the unsafe behavior, a minimal reproduction, and any known
mitigation. Do not open a public issue for an unpatched vulnerability that could expose data or cause
destructive actions.
